# Proyecto TV - cómo usarlo
- Videos: copiá `stella_video.mp4`, `flujo_video.mp4` y `femon_video.mp4` dentro de la carpeta `videos/`.
- Códigos Downloader, links de celular, precios y textos: editá `js/config.js`.
- Para subir a Render: Static Site, Build Command vacío, Publish Directory `.` (o `tv-project` si subís la carpeta completa).
- Tip: comprimí los videos (MP4 H.264) para que carguen rápido; GitHub no admite archivos de más de 100 MB.
